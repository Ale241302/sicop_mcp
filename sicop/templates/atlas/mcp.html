ParámetroValor

URL del servidor MCP remotohttps://sicop.vlinte.work/mcp

Protocolostreamable-http (MCP 2.x)

Cómo usarlo en Claude.ai Configuración → Conectores → agregar servidor remoto → pegar la URL → guardar. Luego preguntale a Claude con lenguaje natural (ver ejemplos).

Desde otro cliente MCP (HTTP crudo) Inicializá la sesión y llamá tools con streamable-http: curl -X POST https://sicop.vlinte.work/mcp \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-03-26","capabilities":{},"clientInfo":{"name":"mi-app","version":"1"}}}' La respuesta trae el mcp-session-id en el header; usalo en las llamadas siguientes (tools/list, tools/call).
